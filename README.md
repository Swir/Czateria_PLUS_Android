# ⚡ CZATeria Plus Android

Mobilna wersja **CZATeria Plus** przygotowana pod Androida, z wybranymi funkcjami XBookmark 9.9 dostosowanymi do ekranu telefonu.

## Najważniejsze funkcje

- 📱 mobilny interfejs dopasowany do telefonu
- 👥 Friend Radar / znajomi
- 🌈 kolorowe pisanie: stały kolor, losowy i tęcza
- 🎨 kolorowe nicki
- 🔔 wyróżnianie wzmianek i opcjonalny dźwięk
- 🖼️ obsługa GIF / kodów Czaterii
- 🚫 ukrywanie reklam w interfejsie aplikacji
- ↔️ górne menu przewijane dotykowo
- ⚙️ ustawienia mobilne bez desktopowego panelu MOD

## Aktualna wersja

**v0.6.3 + XBookmark 9.9 Mobile**

Gotowy plik APK znajduje się w sekcji **Releases**.

## Instalacja

1. Otwórz najnowszy Release.
2. Pobierz plik `.apk`.
3. Zezwól Androidowi na instalację aplikacji z tego źródła, jeśli system o to poprosi.
4. Zainstaluj APK.

> Projekt nie jest oficjalną aplikacją Interii/CZATerii. Jest to niezależny klient/rozszerzenie przygotowane przez Swir.
